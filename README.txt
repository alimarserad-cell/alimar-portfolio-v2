PORTFOLIO WEBSITE - static folder
================================
Open index.html in a browser, or upload this whole folder to any static host
(Vercel: import the folder, framework preset "Other", no build command).

index.html      the portfolio page
css/style.css   all styles
js/script.js    all behaviour (animations, tabs, ID card, smoke, comments)
images/         photos, certificates, logos, tech icons (images/tech)
downloads/      Alimar-Serad-Resume.pdf (linked by the Download Resume button)

Fonts (Outfit, Unbounded, Space Mono) load from Google Fonts, so the first
load needs internet. Everything else is local.
